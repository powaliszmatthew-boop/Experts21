# KPI analytics

## Core KPIs (targets are Estimates; docs/05 and docs/08)
| KPI | Target / reference |
|---|---|
| Transactions/day | ≥ 175 to break even (base case); ≥ 191 at Brickell rent |
| Average ticket | $7.50 base; $6-$12 range |
| COGS % | 25-35% |
| Labor % (incl. taxes) | 25-32% |
| Rent % of sales | ≤ 10-12% at maturity |
| App/online share | Track monthly (national: 40% order by app) |
| Repeat rate (loyalty) | Track monthly |
| Google rating / reviews | ≥ 4.5; review count growing |
| Sales by daypart | Find dead hours and adjust staffing |

## Cadence
Daily: transactions, sales, labor hours. Weekly: COGS, waste, schedule against demand. Monthly: P&L against budget, KPIs, marketing ROI.

## Output
A one-page dashboard spec (metric, definition, source system, owner, target), plus a weekly review agenda.
