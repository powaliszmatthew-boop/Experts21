# Knowledge folder: `funding-capital-advisor` (Alejandro, Funding & Capital Advisor)

`funding-capital-advisor` reads this folder before every answer. Put documents here that only this agent needs and that the shared research in `docs/` doesn't cover.

## What belongs here
- Lender term sheets, SBA forms, investor decks, personal financial statement drafts.
- Newer figures, quotes, or decisions that replace something in `docs/` (put the date in the file name).

## What doesn't belong here
- Research every agent needs: put it in `docs/` and add it to `docs/README.md`.
- Passwords, API keys, account numbers, SSNs, or other secrets.

## Tips
- Name files `YYYY-MM-DD-short-topic.ext` (e.g. `2026-11-23-roaster-quote.pdf`); Markdown, text, CSV, and PDF read best.
- Start each Markdown file with its source and date so the agent can label it (Verified / Reported / Estimate).
