# Experts21

An advisory team of Claude Code subagents for opening an independent specialty coffee shop in Miami. See [`CLAUDE.md`](CLAUDE.md) for how to use the team in Claude Code.

## Web app

[`web/`](web/) is a React chat app for talking to the same experts in a browser: pick one expert from the sidebar or **Ask the whole team** (routed through the orchestrator). It runs on Netlify, and your Claude API key stays in a Netlify Function. Deploy steps: [`web/README.md`](web/README.md).
