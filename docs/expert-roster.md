# Expert Roster: Miami Specialty Coffee Shop

This roster lists the advisory agents for the consultant's engagement and the skills they need. It is built on the research in this folder (see [README.md](README.md)). Each agent is a Claude Code project subagent in `.claude/agents/<agent>.md`, and each skill is a project skill in `.claude/skills/<skill>/SKILL.md`. The **Docs** column lists the research files each agent relies on, by number (e.g. `05` = [05-operating-costs.md](05-operating-costs.md)).

**27 agents · 33 skills.** Skills are shared: the skill table lists which agents use (preload) each skill, and the agent tables list each agent's skills. How to use the team: see [`CLAUDE.md`](../CLAUDE.md). Each agent's model, name, and persona: [agent-brains.md](agent-brains.md). Each agent reads its own knowledge folder, `knowledge/<agent>/`, before answering.

> The legal, tax, and insurance agents give research-level guidance only. A licensed Florida attorney, CPA, or insurance broker must sign off before anything is filed, signed, or bound.

## How the agents work together

1. **`expert-orchestrator`** receives any question, picks experts with `team-routing`, briefs them, runs them in parallel or in sequence, reconciles the results, and returns one answer (`cross-expert-synthesis`).
2. **Site decision first:** `site-selection-advisor`, `competitive-intelligence-analyst`, `lease-attorney`, and `financial-analyst` work together on every candidate location, because rent is the top risk ([09-risks.md](09-risks.md)).
3. **Build and permits:** `architect-buildout-manager`, `cafe-equipment-engineer`, `permitting-expediter`, and `food-safety-specialist` work in sequence. The Certificate of Use comes only after construction ([06-permits-licenses.md](06-permits-licenses.md)).
4. **Product and pricing:** `coffee-sourcing-specialist` → `beverage-menu-lead` → `financial-analyst` is the costing loop.
5. **Launch:** brand, social, PR, and technology run pre-opening; operations and talent handle staffing and training; wholesale adds B2B revenue after opening.
6. **Strategy and upkeep:** `engagement-lead` makes go/no-go calls; `insurance-risk-manager` maintains the risk register; `team-builder` creates and improves agents and skills.
